DualMem provides cross-session project memory shared by supported agent harnesses.

- Search existing project memory before broad code exploration.
- Save durable decisions, warnings, architecture findings, and debugging insights explicitly.
- Include associated file paths when saving code-related memory.
- Use checkpoints to record completed and remaining work on an in-progress task.
- Let the shared DualMem runtime resolve project identity and namespace; do not derive a namespace in harness configuration.
